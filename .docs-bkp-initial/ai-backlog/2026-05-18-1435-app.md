# core/app.ts — remove console output from the core use case

`UsageApp.run()` calls `console.warn` when the stored token looks expired.
Writing to the console is a presentation concern; the core should stay free
of I/O so library consumers using `UsageApp` directly aren't surprised by
stray output.

Suggestion: surface the "token expired" condition through the renderer or a
return value, and let the CLI decide how to display it.
