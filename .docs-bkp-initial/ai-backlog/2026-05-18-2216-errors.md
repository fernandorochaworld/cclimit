# Add automated tests for the error hierarchy

The new `core/errors.ts` types and the failure paths in the adapters
(`anthropic-usage.ts`, `keychain-credentials.ts`) have no automated tests.

Add unit tests that assert each adapter throws the correct
`AiLimitsError` subclass and `code` for every failure (401, non-OK HTTP,
invalid JSON, network failure, missing credentials). This keeps the error
codes — now part of the public API — stable across refactors.
